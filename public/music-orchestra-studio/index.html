🎹 Music Orchestra Studio

AI-powered music composition & synthesis studio. Compose with 9 instruments, edit notes in a canvas piano roll, arrange tracks on a timeline, and generate music with a local LLM (Ollama) or MusicGen. Pure algorithmic synthesis — no samples. Export to WAV.
Python 3.10+ · Flask NumPy / SciPy synthesis Canvas SPA Ollama · MusicGen

What it is

A self-hosted music studio that runs entirely locally — no internet needed for synthesis or Ollama composition. Every instrument sound is generated from scratch with NumPy (no audio samples or external files). A Flask server holds the session state; a vanilla-JS single-page app drives a canvas piano roll and arrangement timeline.

9 instruments
piano, violin, cello, flute, saxophone, trumpet, guitar, bass, drums — each with its own synthesis algorithm in core/synthesizer.py.
Canvas piano roll
Click to add notes, drag to move/resize, grid quantize (1/16…bar), per-note speed & volume, local undo/redo, auto-save.
Arrangement timeline
Note-density heatmap per track, animated playhead (~60fps), zoom 0.25×–8×, drag to offset, right-click context menu.
AI composition
Ollama LLM turns a text style into structured tracks (melody/chords/bass/drums). MusicGen generates raw audio.
Multi-format input
Scientific (C4), MIDI (60), Hz (440.0), solfège (Do4), ABC (c), rests (R) — freely mixed in one line.
Export & playback
WAV export for each track, the orchestra mix, and MusicGen output; in-browser playback, no plugin.

All features above are described in the repo's README.md. This page is an interactive explainer; the full app is a Flask server you run locally with python3 app.py at http://localhost:5000. The Piano Roll (live) tab here ports all nine synth_*() functions to the Web Audio API so you can hear the real voices in your browser.

AI composition (Ollama)

In synthesis/ai_composer.py, a system prompt instructs a local LLM (llama3.2) to emit a JSON array of tracks. Real constraints from that prompt:

  • instrument ∈ piano · violin · cello · flute · saxophone · trumpet · guitar · bass · drums
  • role ∈ chords · melody · bass · rhythm (only drums may use rhythm)
  • chords: 6–8 chord symbols as an array · melody/bass: 8–12 note objects
  • Bass notes use octave 2–3 only; melody notes use octave 4–5
  • drums pattern ∈ rock · jazz · waltz · march · bossa_nova · reggae · funk
  • Write 3–4 tracks; if the style has rhythm, always include drums and bass

The request is sent with format: 'json' to the Ollama chat API. Modes (from README): add tracks, extend session, replace all.

Synthesis methods

Every instrument has a dedicated synth_* function in core/synthesizer.py. Each returns a float32 NumPy array in [−1, 1] at 44100 Hz. The table is verbatim from the repo; the live piano-roll tab ports each one to the Web Audio API.

InstrumentAlgorithm (from synthesizer.py)
pianoAdditive: 8 harmonics [1, .5, .25, …], per-harmonic exponential decay exp(−t·(1+h·0.25)), fast attack + short release
violinPhase-integrated vibrato (5.5 Hz, fades in after 120 ms), 10 harmonics [1,.72,.52,…], high-pass bow noise, slow ADSR
celloDarker bowed string: 9 harmonics (1/k, then 0.5/k above the 4th), slower 4.5 Hz vibrato, long 120 ms attack
fluteSine-dominant (1 + .15·h2 + .05·h3) + low-passed breath noise + delayed 4.8 Hz vibrato
saxophoneRich harmonics [1,.8,.6,…] + reed-buzz transient exp(−15t), ADSR with 0.85 sustain
trumpetBright 8 harmonics [1,.9,.7,…] + brassy attack buzz exp(−25t), punchy 15 ms attack
guitarKarplus-Strong plucked string: noise burst through a damped delay line (damping 0.996)
bassKarplus-Strong with higher damping (0.998) → warmer, longer-sustaining tone
drumsGM-mapped: kick = pitch-swept sine (150→50 Hz), snare = noise + 200 Hz body, hi-hat = high-passed noise

Drums decode MIDI numbers as drum types (36=kick, 38=snare, 42=hihat, 46=openhat, 49=crash, 45/47/50=toms) — see instruments/drums/drums.py.

Reference: synth_piano() & synth_violin()

The two voices below show the additive-decay vs. phase-integrated-vibrato approaches the WebAudio port mirrors. The browser uses oscillators + gain envelopes instead of NumPy arrays, but the harmonic amplitudes and decay/envelope shapes are the same.

PIANO_HARMONIC_AMPS = [1.0, 0.50, 0.25, 0.125, 0.063, 0.031, 0.016, 0.008] def synth_piano(freq, duration, velocity=0.8, sr=44100): t = np.linspace(0, duration, int(duration*sr), endpoint=False) wave = np.zeros_like(t) for h, amp in enumerate(PIANO_HARMONIC_AMPS, start=1): decay = np.exp(-t * (1.0 + h * 0.25)) # higher harmonics decay faster wave += amp * np.sin(2*np.pi*freq*h*t) * decay env = make_adsr(n, attack_s=0.005, decay_s=0.0, sustain=1.0, release_s=min(0.12, duration*0.2)) return _normalize(wave * env * velocity) def synth_violin(freq, duration, velocity=0.8, sr=44100): vibrato_env = np.clip((t - 0.12) / 0.10, 0.0, 1.0) # fades in after 120 ms vibrato = 1.0 + 0.0028 * vibrato_env * np.sin(2*np.pi*5.5*t) fund_phase = np.cumsum(2*np.pi*freq*vibrato / sr) # locked harmonics amps = [1.0, 0.72, 0.52, 0.35, 0.22, 0.14, 0.09, 0.05, 0.03, 0.02] wave = sum(a * np.sin(k*fund_phase) for k, a in enumerate(amps, 1)) wave += highpass(np.random.standard_normal(n) * 0.018) # bow noise return _normalize(wave * make_adsr(...) * velocity)

core/synthesizer.py, lines 61–151. In the live tab, vibrato is an OscillatorNode LFO on the carrier frequencies and bow/breath noise is a filtered AudioBufferSourceNode.

Duration & speed overrides

C4 E4 G4 C5:2 C5 held for 2 beats C4:1:2.0 C4, 1 beat, 2× speed (staccato) C4 D4 60 440.0 Do4 c R G4 mixed formats in one line

A=440 reference: midi_to_hz(midi) = 440 · 2^((midi−69)/12). velocity is a speed multiplier (1.0 = normal, 2.0 = twice as fast), distinct from per-note volume (loudness 0–1).

REST API (selected endpoints)

Verbatim from README.md / SYSTEM.md. All endpoints read/write the shared in-memory OrchestraEngine.

GET /api/instruments all instruments and preset tunes GET /api/tracks current track list and state POST /api/tracks/add { instrument } add a new track DELETE /api/tracks/<id> remove a track GET /api/track/<id>/notes get notes for a track PUT /api/track/<id>/notes { notes } replace notes for a track POST /api/track/<id>/duplicate duplicate a track POST /api/track/<id>/clear clear all notes POST /api/orchestra { bpm } render all active tracks → WAV POST /api/settings { track_id,... } volume/pan/reverb/bpm/transpose POST /api/generate { prompt,...} Ollama LLM composition POST /api/musicgen { prompt,...} MusicGen audio generation GET /api/arrangement per-track note density (timeline) POST /api/synth { type,data,bpm } synthesize from chords/tab/notes POST /api/midi { file } import MIDI file GET /audio/<filename>.wav serve generated audio
