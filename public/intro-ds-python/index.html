k-means — the repo's algorithm, live

HW02 clusters London-bike rows on (cnt, hum). This demo reimplements kmeans(): pick k random initial centroids, assign each point to its nearest centroid (Euclidean), recompute centroids as the cluster mean, and repeat until centroids stop moving.

Press Step to run one assign/recompute iteration.

Points = synthetic 2-D blobs (so the page is self-contained); stars = centroids. The logic — distance matrix, argmin assignment, mean recompute, convergence test — is exactly the repo's.

The real loop — clustering.py

def kmeans(data, k):
    prev_centroids = None
    current_centroids = choose_initial_centroids(data, k)
    while not np.array_equal(prev_centroids, current_centroids):
        labels = assign_to_clusters(data, current_centroids)
        prev_centroids = current_centroids
        current_centroids = recompute_centroids(data, labels, k)
    return labels, current_centroids

def assign_to_clusters(data, centroids):
    return np.argmin(distance_matrix(data, centroids), axis=1)

HW01 — statistics from first principles

No numpy shortcuts: mean, sample standard deviation and covariance are written by hand in statistics.py.

def calc_mean(values):
    return sum(values) / len(values)

def calc_stdv(values):
    return sqrt(sum(map(lambda x: (x - calc_mean(values))**2, values)) / (len(values) - 1))

def calc_covariance(val1, val2):
    return sum(map(lambda x: (x[0]-calc_mean(val1)) * (x[1]-calc_mean(val2)),
                   list(zip(val1, val2)))) / (len(val1) - 1)

The driver (main.py) loads the London CSV, filters by season and is_holiday, and reports mean/stdv of hum, t1, cnt plus Cov(t1, cnt) for Summer / Holiday / All, then splits Winter records by a temperature threshold.

Findings (from the repo's hw01_part2.txt)

1
Prefer the median over the mean here — a few records with very large cnt skew the mean/stdv, so the median is more representative.
2
On holidays, when temperature is above 13°, bike usage more than doubles; on weekdays there's no substantial temperature effect on count.
3
Cov(season, temp) is misleading because seasons are encoded as arbitrary cyclic integers (0–3); the relationship isn't linear, and the result is a small negative number indicating little linear correlation.

These conclusions are quoted/paraphrased from Gil's written answers in the repo.
