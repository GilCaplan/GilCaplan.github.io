The shared environment

  • Map tiles: 'P' passable, 'I' impassable wall, 'V' Voldemort's seat. In ex1.py these are parsed to integers P=1, I=0, V=2.
  • Wizards (incl. Harry Potter) each have a location and HP; Death Eaters patrol fixed paths (path = de + reversed(de[1:-1]), cycled by move_num) and damage any wizard standing on their current cell.
  • Horcruxes sit on tiles and must be destroyed before Voldemort can be killed.
  • Goal (HW1): reach voldemort_killed = True — only Harry, only after all horcruxes are gone, and only on a strictly later move than the last horcrux was destroyed.

What's faithfully ported — HW1/ex1.py + search.py

  • State (JSON string, the node's identity): {wizards:{name:[[r,c],hp]}, horcruxes:{i:[[r,c],done]}, move_num, horcruxes_destroyed, voldemort_killed}.
  • actions(state): per wizard build move / destroy / wait / kill options (only Harry may step onto V, and only once all horcruxes are gone; "unsafe" = standing on a Death-Eater's current patrol cell), then itertools.product over wizards.
  • result(state, action): advance move_num, apply each atomic action, then dock HP for any wizard sharing a tile with a Death Eater this turn.
  • goal_test: voldemort_killed == True. h(): ∞ if a wizard is dead, BFS distance to Voldemort when ≤1 horcrux remains, else a greedy min-distance horcrux↔wizard assignment.

The Bellman backup it computes — HW3/ex3.py value_iteration()

  • States: Cartesian product of wizard positions × horcrux locations × Death-Eater path indices (generate_all_environments).
  • Transition model: horcrux stays w.p. 1−prob_change else jumps uniformly (get_next_locs_probs_horcrux); DE index does a ±1 random walk (get_next_locs_probs_death_eaters).
  • Reward: +2 per destroy, −1 per Death-Eater collision (check_collision), −2 for reset.
  • Backup: policy[k][s] = argmaxa( R(s,a) + Σ P·policy[k-1][s'].value ) for k = 1 … turns_to_go; act() just looks up policy[turns_to_go][s][0].

What's faithfully ported — HW2/ex2.py + ex2_dpll.py

  • _process_observations: ("dragon",loc)→known_dragons; ("vault",loc)→known_vaults; sulfur ⇒ every adjacent tile not already safe/dragon joins potential_traps; no sulfur ⇒ adjacent tiles become known_safe and are cleared from suspicion.
  • get_next_action ladder (ex2.py): (1) on an un-looted vault → collect; (2) else A*-path to nearest known vault — if next step is a suspected trap, destroy it, else move; (3) else explore neighbours (ranked: unvisited > non-trap > non-dragon > non-dead-end); (4) else backtrack along self.path via _astar to the nearest tile with unexplored neighbours.
  • _astar: Manhattan-heuristic A* restricted to known_safe ∖ known_dragons — the agent can only plan through tiles it has proven safe.
  • ex2_dpll.py variant: same sulfur⇒adjacent-trap / no-sulfur⇒safe inference, but the decision rule is the simpler "move to nearest safe unvisited neighbour, else destroy an unsafe neighbour, else wait" — the CNF/DPLL knowledge-base form from the logic part of the course.

HW1 — admissible heuristic — ex1.py

def h(self, node):
    new_state = json.loads(node.state)
    wizards = new_state['wizards']; horcruxes = new_state['horcruxes']
    if any(wizards[w][1] <= 0 for w in wizards): return float('inf')
    horcrux_positions = tuple([(x,y) for [(x,y),h] in horcruxes.values() if not h])
    x,y = wizards["Harry Potter"][0]
    if len(horcrux_positions) < 2:
        return self.shortest_dist_from_voldemort[x][y]   # precomputed BFS
    wiz_locs = tuple([(x,y) for wiz,[(x,y),_] in zip(wizards, wizards.values())])
    return self.compute_wizard_horcrux_distances(wiz_locs, horcrux_positions)

HW2 — sulfur deduction + A* over known-safe — ex2.py

def _process_observations(self, observations):
    y, x = self.harry_loc
    adjacent = self._get_adjacent_tiles(y, x)
    has_sulfur = False
    for obs in observations:
        if obs[0].lower() == "dragon": self.known_dragons.add(obs[1]); self.known_safe.discard(obs[1])
        elif obs[0].lower() == "vault":  self.known_vaults.add(obs[1])
        elif obs[0].lower() == "sulfur": has_sulfur = True
    if has_sulfur:                              # a trap is adjacent
        safe_and_dragons = self.known_safe.union(self.known_dragons)
        self.potential_traps.update(t for t in adjacent if t not in safe_and_dragons)
    else:                                       # no sulfur ⇒ neighbours safe
        self.known_safe.update(adjacent); self.potential_traps.difference_update(adjacent)

def _astar(self, start, goal):                  # plan only over PROVEN-safe tiles
    open_set = [(h(start), 0, start, [])]; visited = {start}
    while open_set:
        _, g, cur, path = heapq.heappop(open_set)
        if cur == goal: return path
        for adj in self._get_adjacent_tiles(*cur):
            if adj in self.known_safe and adj not in self.known_dragons and adj not in visited:
                visited.add(adj); heapq.heappush(open_set, (g+1+h(adj), g+1, adj, path+[adj]))

The get_next_action() ladder then does: collect on a vault → A*-path to nearest known vault (destroy a suspected trap in the way, else move) → explore ranked neighbours → backtrack. ex2_dpll.py keeps the same inference but a simpler CNF-style "nearest safe neighbour" policy.

HW3 — finite-horizon value iteration — ex3.py

def value_iteration(self):
    policy = [{} for _ in range(self.turns + 1)]
    for state in self.all_states:
        policy[0][state] = ("terminate", self.check_collision(state))
    for k in range(1, self.turns + 1):
        for state in self.all_states:
            R = self.check_collision(state)            # -1 per DE collision
            best_action = ("terminate", 0)
            for action in actions:                     # +2 destroy, -2 reset
                v = current(action) + Σ prob · policy[k-1][s'][1]
                if v > best_action[1]: best_action = (action, v)
            policy[k][state] = (best_action[0], best_action[1] + R)
    return policy

Reward constants live at the top of ex3.py: DESTROY_HORCRUX_REWARD = 2, RESET_PENALTY = 2, DEATH_EATER_PENALTY = 1.
