What the first conv layer "sees"

The 8 feature maps produced by the first convolutional block (Conv 3→8, k4 s2 + BatchNorm + SiLU) on your image — early filters fire on edges, colour blobs and texture. Brighter = stronger activation.

About this model

  • Task / dataset: 4-class dog-emotion classification (Dog_Emotion: angry / happy / relaxed / sad), 128×128 RGB, ~2800 train / 400 val / 800 test images.
  • Architecture: 5 conv blocks (Conv+BatchNorm) growing 3→8→16→32→64→128 channels, SiLU activations, 2×2 max-pooling, adaptive average-pool to 1×1, then FC 128→8→4. 100,116 parameters.
  • Metric: 67.9% test accuracy (reported in the notebook); chosen by best validation accuracy over 300 epochs.
  • Weights: the exact trained parameters from HW1_ML02_model.pkl. BatchNorm is folded into the preceding conv at export, so the browser runs the identical eval-mode function.
  • Parity: the JS forward pass matches the original PyTorch model to < 7e-6 max-abs logit difference across test inputs. The bundled German-Shepherd photo predicts sad (~0.99) in both.
  • Note: browser image resizing differs slightly from PyTorch/PIL, so probabilities on uploaded photos can shift a little versus a Python run on the same file — the network and weights are identical.

Manual forward + backward pass — HW1_solution_ML2.ipynb

No autograd: gradients are the hand-derived softmax + cross-entropy result (ŷ − y)/N, propagated through the hidden layer.

def forward(self, X):
    self.z1 = X @ self.W1 + self.b1
    self.h  = self.activation(self.z1)        # sigmoid
    self.z2 = self.h @ self.W2 + self.b2
    return softmax(self.z2)

def backward(self, X, y, y_hat):
    n = y.size(0)
    dl_dz2 = (y_hat - y) / n                   # softmax+CE gradient
    dl_dW2 = self.h.T @ dl_dz2;  dl_db2 = dl_dz2.sum(0)
    dl_dh  = dl_dz2 @ self.W2.T
    dl_dz1 = dl_dh * self.d_activation(self.z1)
    dl_dW1 = X.T @ dl_dz1;       dl_db1 = dl_dz1.sum(0)
    self.W2 -= self.lr*dl_dW2;   self.b2 -= self.lr*dl_db2   # manual SGD
    self.W1 -= self.lr*dl_dW1;   self.b1 -= self.lr*dl_db1

Activation derivatives (Q2.I)

def d_sigmoid(x):
    return torch.exp(-x) / (1 + torch.exp(-x))**2

def d_softmax(x):
    s = softmax(x)
    if len(x.shape) == 1:
        return torch.diag(s) - torch.outer(s, s)          # Jacobian
    return torch.diag_embed(s) - torch.bmm(s.unsqueeze(-1), s.unsqueeze(1))

The dry part proves ∂softmax_i/∂x_k = softmax_i(δ_ik − softmax_k) and that the cross-entropy gradient collapses to ŷ − y.
