The arc of the course

Each homework adds one layer of the diffusion-model picture. By HW4 the pieces combine into a guided image generator with quantitative FID evaluation.

HW1 · Score matching & Langevin

Density & score of a 2D Gaussian mixture from scratch, train a score network, then sample via (annealed) Langevin dynamics — finishing with MNIST image generation by denoising score matching.

HW2 · DDPM

A denoising diffusion probabilistic model trained on Fashion-MNIST. Three saved checkpoints (mean / variance / noise models) and 12 saved sample grids across training.

HW3 · Score-based SDEs

Reproduces Song et al. (2021): Variance-Preserving SDEs, Euler–Maruyama simulation, Anderson's reverse SDE, the probability-flow ODE, and conditional (classifier-guided) generation.

HW4 · DDIM & guidance

Implements DDPM/DDIM sampling on a 2D spiral (Chamfer-distance scored) and class-conditional image diffusion on AFHQ with classifier-free guidance (FID-scored).

Headline results from HW4/HW4_report.pdf (real numbers): DDPM Chamfer 11.53, DDIM Chamfer 10.32, image FID 4.76 (no guidance) → 0.34 with CFG scale 7.5.

Forward noising & reverse denoising

The shared backbone of every assignment. The forward process gradually adds Gaussian noise; a network learns to reverse it one step at a time. Drag the slider to walk through diffusion timesteps on a 2D point cloud.

The closed-form forward step (real code, ddpm.py)

x_t = √(ᾱ_t)·x_0 + √(1−ᾱ_t)·ε,   ε ~ N(0, I)
def q_sample(self, x0, t, noise=None):
    if noise is None: noise = torch.randn_like(x0)
    alphas_prod_t = extract(self.var_scheduler.alphas_cumprod, t, x0)
    xt = alphas_prod_t.sqrt() * x0 + (1 - alphas_prod_t).sqrt() * noise
    return xt

The model is trained with the simplified noise-matching objective (DDPM Eq. 14): predict the noise ε that was added.

L = E ‖ ε − ε_θ(x_t, t) ‖²
def compute_loss(self, x0):
    t = torch.randint(0, self.var_scheduler.num_train_timesteps, (B,))
    noise = torch.randn_like(x0)
    x_t = self.q_sample(x0, t, noise)
    noise_pred = self.network(x_t, t)
    return F.mse_loss(noise_pred, noise)

def q_sample(self, x0, t, noise=None):
    if noise is None: noise = torch.randn_like(x0)
    a_bar = self.var_scheduler.alphas_cumprod[t]        # ᾱ_t
    return a_bar.sqrt() * x0 + (1 - a_bar).sqrt() * noise
At small t the image is barely perturbed; as ᾱ_t → 0 the signal term vanishes and x_t becomes the pure Gaussian sample the reverse process starts from. The cosine schedule keeps ᾱ_t higher for longer, so information is destroyed more gradually than the linear schedule — the key fix from Nichol & Dhariwal (2021) that the course's HW2/HW4 build on.

HW1 · Score matching & Langevin dynamics

Notebook: HW1/HW1_337604821.ipynb — "Score Matching and Langevin Dynamics".

Part 1
GMM density + score (closed form)→ Part 2
train a score network→ Part 3
sample via Langevin dynamics→ Final
MNIST via denoising score matching + UNet

What the notebook actually does

  • Implements the density and score ∇ₓ log p(x) of a 2D Gaussian Mixture Model without using torch.distributions, visualized as a heatmap + quiver (arrow) field.
  • Trains a network to predict the score; the assignment requires the training loss below 0.01, and compares model vs. true score (they diverge in low-density regions).
  • Samples 1000 points three ways: direct, plain Langevin dynamics, and annealed Langevin dynamics across decreasing noise scales.
  • Final section: denoising score matching with a provided UNet to generate MNIST digits via annealed Langevin dynamics.
Langevin step:  x_{t+1} = x_t + (η/2)·∇ₓ log p(x_t) + √η · z,  z ~ N(0,I)
Grounded in the notebook's markdown: "Part 1: Computing the density and score of a GMM", "Part 2: Training a score network", "Part 3: Sampling … using Langevin Dynamics … Annealed Langevin Dynamics", then "Putting it all together!" on MNIST.

HW3 · Score-based generative modeling through SDEs

Notebook HW3/HW3_sol.ipynb — reproduces parts of Song et al., arXiv:2011.13456.

Parts implemented (from the notebook)

1.1–1.3 · Simulating SDEs

Recreates Figure 2 of the paper with Euler's method, using the Variance-Preserving SDE.

dx_t = −½ β_t x_t dt + √(β_t) dw_t

1.4 · Probability-flow ODE

Derives the deterministic ODE whose marginals match the SDE, removing the noise term.

1.5 · Reverse SDE

Anderson's reverse-time SDE driven by the learned score ∇ₓ log pₜ(x).

3–4 · DDPM-as-score + conditional

Views the trained DDPM as a score network, then does classifier-guided conditional generation toward a target class.

Reverse-time SDE (the core equation, from the notebook)

dx = [ μ(x,t) − σ²(t) ∇ₓ log pₜ(x) ] dt + σ(t) dw̄
The notebook explicitly derives the VP-SDE forward process, the reverse SDE (Anderson), the probability-flow ODE (bonus), histograms of x_t over time via pcolormesh, and Part 4's class-conditional generation with a classifier guidance strength γ.

HW4 · DDPM / DDIM sampling & classifier-free guidance

Code in HW4/HW4_code/; results & metrics in HW4/HW4_report.pdf and HW4/HW4_3_images/.

Task 1–2 · 2D spiral (Chamfer distance)

A diffusion model is fit to a 2D spiral distribution; quality is the Chamfer distance between 2048 generated and reference points (lower is better). DDIM uses a quadratically-spaced timestep subsequence for faster sampling.

11.53DDPM Chamfer distance (Task 1)
10.32DDIM Chamfer distance (Task 2, η=1.0)
pc_gen = ddpm.p_sample_loop(shape=(2048, 2))          # DDPM  → 11.5294
pc_gen = ddpm.ddim_p_sample_loop(shape=(2048, 2), eta=1.0)  # DDIM  → 10.3217

Both clear the assignment thresholds (DDPM < 20, DDIM < 40). The DDIM one-step update implemented in ddpm.py:

predicted_x0 = (xt - √(1-ᾱ_t)·ε_θ) / √(ᾱ_t)
x_{t-1} = √(ᾱ_prev)·predicted_x0
        + √(1-ᾱ_prev-σ²)·ε_θ
        + σ·z          # σ=0 ⇒ deterministic DDIM
