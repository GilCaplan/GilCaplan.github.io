What's in this repo

A small set of database / distributed-data report scripts (the IDE project is named DataBase_Spring). The work spans three practical tasks: flattening nested JSON into a tabular feed, distributed aggregation with MapReduce (mrjob) and Apache Spark, and a Monte-Carlo analysis of a small stochastic process.

Flattens to columns like stats.hp, stats.attack, type.0, type.1, abilities.0, evolution.0… A regex also extracts the parenthesized metric value from strings (e.g. "2ft.4in. (0.71m)" → "0.71m").

def flatten_json(nested_json, parent_key='', sep='.'):
    items = []
    for k, v in nested_json.items():
        new_key = f"{parent_key}{sep}{k}" if parent_key else k
        if isinstance(v, dict):
            items.extend(next(flatten_json(v, new_key, sep)).items())
        elif isinstance(v, list):
            for i, item in enumerate(v): ...   # index into key
        else:
            if isinstance(v, str):
                m = re.search(r'\((.*?)\)', v)  # pull "(0.71m)"
                if m: v = m.group(1)
            items.append((new_key, v))
    yield dict(items)

Distributed aggregation — MapReduce & Spark

Two distributed jobs over TV-viewing logs. report2.py uses mrjob with a multi-step pipeline; the notebook ddHW1q1a.ipynb uses PySpark (sc.textFile) with a hand-written CSV splitter that handles quoted fields containing commas.

Multi-step mrjob: most-viewed program (report2.py)

class MRMostUsedViewed(MRJob):
    def steps(self):
        return [
            MRStep(mapper=self.mapper_get_words,        # emit (prog_code, 1)
                   combiner=self.combiner_count_words,  # local sum
                   reducer=self.reducer_count_words),   # global sum → (count, prog)
            MRStep(reducer=self.reducer_find_max_word)  # max over all programs
        ]
    def mapper_get_words(self, _, row):
        if 20000 <= row['event_time'] <= 2300:
            yield (row['prog_code'], 1)
    def reducer_find_max_word(self, _, pairs):
        yield max(pairs)        # (count, prog) — Python max picks largest count

The classic word-count pattern, repurposed: map each viewing event to its program code, combine partial counts locally, sum globally, then a second reduce step takes the max. A companion class MRCountMostViewers then counts viewers of that top program.

Spark job with custom CSV parsing (ddHW1q1a.ipynb)

data   = sc.textFile('tiny_50k_daily_prog_data.csv.csv')
header = data.first()

class MRWordFrequencyCount(MRJob):
    def mapper(self, _, line):
        title, genres, air_time, date = split_properley(line)  # quote-aware CSV split
        if line != header and 70000 <= air_time < 90000:
            for l in ['j','q','z']:
                if l in title.lower():
                    for k in ['Sitcom','Talk','Politics','Spanish',...]:
                        if k in genres:
                            yield ((title, date, genres), 1)

split_properley finds quote positions to correctly split rows where the title or genre field itself contains commas — then the job filters by air-time window, title letters (j/q/z) and a genre whitelist, and counts matches.

Markov-chain hitting time — live Monte-Carlo (report3.py)

A small stochastic process on states 0,1,2,3. From states 0 and 1 you always advance by one. From state 2 you reset to state 0 with probability min(1, (state−1)/10) = 0.1, otherwise advance to state 3. State 3 is absorbing. The script runs 1,000 simulations and reports the mean number of steps to reach state 3. Run it here — same logic as the repo.

def simulation():
    time, curr_state = 0, 0
    while curr_state < 3:
        if curr_state in [0, 1]:
            curr_state += 1; time += 1
        else:
            if random.random() < min([1, (curr_state-1)/10]):
                curr_state = 0; time += 1          # reset
            else:
                time += 1; curr_state += 1          # advance
    return time

score = [simulation() for _ in range(1000)]
print(np.mean(score))
