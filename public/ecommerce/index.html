Technion e-commerce course, three assignments. HW01 is the flagship: pick a seed set to maximize a product launch's spread across a real 4,039-person friendship network, solved with a greedy hill-climb and a genetic algorithm — running live below, on the real graph. HW02 and HW03 are lighter live demos of the other two assignments' core algorithms.

Simplifications, disclosed: the visible/candidate pool is the real top-1,000 people by real degree centrality (cost = 100 only) — matching the real assignment's ~800–1,000-node pool size. The real pool ranked by degree and betweenness centrality; betweenness is a multi-minute computation even offline, so it's omitted here to keep this a live in-browser build (degree centrality alone gets very similar top candidates on a network this size). Each reach estimate averages 5 Monte Carlo trials instead of the real 20–33, to stay responsive — same graph, same costs, same diffusion formulas (buy_products / product_exposure_score), same greedy and genetic mechanics (population 20, 50 generations, exactly as submitted).

HW02's Recommender class doesn't know the user's type — it maintains a posterior belief over which of several viewer types it's talking to, and sharpens that belief after every recommendation using the same likelihood-ratio update the real update() method runs: multiply by L (probability of a like) on a like, or by (1−L)·S (probability of a dislike and staying) on a dislike, then renormalize.
