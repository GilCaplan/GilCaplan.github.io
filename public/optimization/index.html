What the course covers

An introductory course in nonlinear continuous optimization, emphasizing convex optimization. From the repo README, the goals are to model real problems as convex programs, solve them with basic algorithms and CVXPY, analyze algorithm performance, and develop new methods from convex theory.

Exact step for ‖Ax−b‖²

For the quadratic least-squares objective the exact line-search step has a closed form. From HW05.py:

def exact_quad(f, xk, gk, A):
    # t = ‖g‖² / (2‖A·g‖)²  — exact step for the quadratic
    return (np.linalg.norm(gk)**2) / ((2*np.linalg.norm(A.dot(gk)))**2)

Accelerated gradient (FISTA)

HW05 also implements Nesterov-style acceleration with the tₖ momentum recursion:

# inside AG(f, gf, L, x0, max_iter)
x.append(y[k] - g/L)
t.append((1 + sqrt(1 + 4*t[k]**2))/2)
y.append(x[k] + ((t[k]-1)/t[k+1])*(x[k]-x[k-1]))

L is the Lipschitz constant of ∇f (twice the top eigenvalue of AᵀA; in the repo L≈1.9995).

Gradient method — watch it descend (or diverge)

The plain generic_grad rule from the repo, x_{k+1} = x_k − t·∇f(x_k), run on a convex test function. Drag the white start point anywhere on the contour map; move the step size t slider. With a small enough step the iterates march down to the minimum (●); push t past the stability limit 2/L and the same method diverges, exactly the convergence condition from the course.

0.100 60

For a quadratic f(x)=½xᵀAx the gradient method converges iff 0 < t < 2/L where L = largest eigenvalue of A (the Lipschitz constant of ∇f). The slider's red zone marks t > 2/L for the bowl, where you'll see the path spiral out.

Step rules race — exact line search vs fixed 1/L vs FISTA

HW05 implements three drivers on the least-squares objective f(x)=‖A·x − b‖²: generic_grad (gradient method with the closed-form exact_quad step), generic_grad_b (constant step 1/L), and AG (Nesterov/FISTA acceleration). Here all three are run live on a small 2-D instance of the same objective so you can watch their iterates and the f-value curve — exactly the semilogy(fs) plot the repo draws. Drag the white start point.

30

On this convex quadratic all three converge to the same least-squares solution x* = (AᵀA)⁻¹Aᵀb. FISTA's O(1/k²) rate and the exact step both reach machine-tolerance in a handful of iterations, while the fixed 1/L step is the slowest — the very comparison HW05 was set up to make.

Projected gradient descent — live

This is the exact algorithm from HW08.py: minimize f(x)=‖x‖² with ∇f(x)=2x, projecting each iterate onto the set the repo's proj_section_b projects to — the line x₀ − x₁ = 1. Same starting point and step as the source.

100 100 0.50

The objective minimizes the squared norm subject to the constraint, so it converges to the point on the feasible line nearest the origin — (0.5, −0.5). With the repo's defaults it converges in a handful of steps.

Facility location — find the best storage site

HW08 Q2 (q2_c_wet.ipynb) places a storage location x to minimise the weighted shipping cost to 50 customers: min_x γ·Σᵢ pᵢ·α·‖Aᵢ − x‖, where the repo builds the data with np.random.seed(314) — 50 shipment points Aᵢ (the first 10 are far-away outliers, shown in red), demand weights pᵢ, and α=0.01, γ=1.2. The repo hands this convex program to CVXPY; here the identical objective is minimised live by Weiszfeld iteration so you can watch the site converge. Drag the white marker to set the start, or click Step.

Because cost is the (weighted) sum of distances, the optimum is the weighted geometric median — robust to the outlier cluster, so it settles among the dense customers rather than being pulled toward the far group. HW08's part B adds piecewise max(0, μ(α‖Aᵢ−x‖ − η)) over-distance penalties on top of this same term.

Projected gradient (HW08.py)

def grad_proj(f, gf, proj, t, x0, eps):
    x_prev = x0
    xk = proj(x_prev - t * gf(x_prev))
    fs = [f(xk)]
    while np.linalg.norm(xk - x_prev) > eps:
        x_prev = xk
        xk = proj(x_prev - t * gf(x_prev))
        fs.append(f(xk))
    return xk, fs

def proj_section_b():
    return lambda p: np.array([(p[0]-p[1]+1)/2, (p[1]-p[0]+1)/2])

f  = lambda x: np.linalg.norm(x)**2
gf = lambda x: 2*x
x, fs = grad_proj(f, gf, proj_section_b(), 0.5, np.array([100, 100]), 1e-8)

CVXPY constrained program (HW08.py)

x = cp.Variable(3)
A = np.array([[1, 1/2, 0],[1, 0, 0],[0, 15**0.5/2, 0],[0, 0, 0]])
D = np.array([1, -1, 1]); E = np.array([1, 1, 0]); y = np.array([0,0,0,2]); b = 1
objective = cp.Minimize(cp.square(x[0]+x[1]) + cp.square(x[1]) + cp.square(x[2])
                        + 3*x[0] - 4*x[1])
constraints = [cp.norm(A @ x + y) + cp.quad_over_lin(D @ x + b, E @ x) <= 6, x >= 1]
result = cp.Problem(objective, constraints).solve()

A conic + quadratic-over-linear constrained convex program handed straight to the CVXPY solver — the "solving with off-the-shelf tools" objective from the README.

Image deblur driver (HW05.py)

# blur() builds a 256² Gaussian Toeplitz blur operator A (Kronecker of 1-D blurs)
A, b, x = blur(256, 5, 1)
AA = A.T.dot(A)
f  = lambda x: np.linalg.norm(A.dot(x) - b) ** 2   # least-squares fidelity
gf = lambda x: 2*AA.dot(x) - 2*A.T.dot(b)         # gradient
l  = 1.9994981175712248                          # Lipschitz const of ∇f
x0 = np.zeros(np.shape(b))
x, fs, gs, ts = AG(f, gf, l, x0, max_iter=1000)  # accelerated gradient
