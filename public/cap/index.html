cap.
A scripting language for AI agents — written in Rust
interactive explainer · showcase
No blocks, no semicolons, no boilerplate — just expressions and pipelines. Variables without let, functions as lambdas, |> pipelines, a huge built-in stdlib, and a pyval Python bridge. Everything below is copied verbatim from the repository (README, QUICKSTART, LANGUAGE.md, and tests/*.cap).

Variables & strings

# No let/var/const — just name = value
x = 42
name = "Alice"
active = true
nothing = null

# Embed any expression with {...}
greeting = "Hello, {name}! Next year you'll be {age + 1}."

Double-quoted strings. Interpolate with {...}; literal braces are {{ / }}.

Functions are lambdas

code (QUICKSTART §4)
double  = |x| x * 2
add     = |a, b| a + b
greet   = |name| "Hello, {name}!"
zero    = || 42          # no-arg lambda

# Closures capture the enclosing scope
make_adder = |n| |x| x + n
add5 = make_adder(5)
documented results
double(5)       # => 10
add(3, 4)       # => 7
add5(3)         # => 8

Pipelines |>

code (README / QUICKSTART §5)
result = [1, 2, 3, 4, 5]
  |> filter(|x| x > 2)
  |> map(|x| x * 10)
  |> sum
documented result
# => 120

|> passes the left value as the first argument of the right call. Wrap a pipeline in () to span multiple lines.

Control flow — if & match are expressions

# if always needs then + else
label = if score >= 90
  then "A"
  elif score >= 80
  then "B"
  else "C"
# match with comma-separated arms
msg = match code,
  0 -> "ok",
  1 -> "warn",
  _ -> "error"

Loops & do…end

code (QUICKSTART §6b)
i = 0
total = 0
while i < 5 do
  total = total + i
  i = i + 1
end
println(total)
documented result
# => 10

Classes — desugar to a constructor returning a map of closures

code (README / QUICKSTART §11)
class Point(x, y),
  dist = || (x*x + y*y) ** 0.5,
  str  = || "({x}, {y})"

p = Point(3, 4)
documented results
p.dist()   # => 5.0
p.str()    # => "(3, 4)"

Methods read constructor args via closure — no self. Inheritance uses extends (see tests/oop.cap & test_class_inheritance.cap).

Null safety & optional chaining

code (LANGUAGE.md)
port = config["port"] ?? 8080   # ?? = null-coalesce

city = user?.address?.city
city = null?.address?.city
documented results
# => "Paris"
# => null

Function composition >>

code (LANGUAGE.md)
double = |x| x * 2
inc    = |x| x + 1
double_then_inc = double >> inc
documented results
double_then_inc(5)   # => 11
5 |> (double >> inc) # => 11
Faithfulness note: the Rust toolchain wasn't available in this environment, so no programs were executed. Every => result shown above is a value the repository itself documents (the # => annotations in README.md / QUICKSTART.md / LANGUAGE.md). No outputs were fabricated.

Install

macOS / Linux — one command (from README.md):

git clone https://github.com/GilCaplan/cap
cd cap
./install.sh   # installs Rust via rustup, builds release, adds cap to PATH

From source (requires Rust 1.70+):

cargo build --release
./target/release/cap --help

CLI

cap <file.cap>           # run a script
cap repl                 # interactive REPL
cap check <file.cap>     # syntax check (no execution)
cap ast <file.cap>       # print AST (debug)

REPL session from the README:

>>> x = [1,2,3,4,5] |> map(|n| n * n) |> sum
>>> println(x)   # => 55

Implementation

CAP is a tree-walking interpreter in Rust. Source layout (src/): lexer/ → parser/ → interpreter/, with main.rs wiring the CLI (clap) and REPL (rustyline). Built on reqwest, serde, rusqlite (bundled), regex, csv, chrono, and the pyval Python bridge for the data-science/ML stdlib.
