HW02 Multiclass Perceptron

One weight vector w_k per class. Predicts argmax_k ⟨w_k, x⟩; on a mistake, subtracts x from the wrongly-chosen class and adds it to the true class. Loops over the data until a full pass makes no update (convergence on separable data).

k-NN decision boundary — slide k, watch it bend

The full decision regions of the repo's KnnClassifier over a non-linearly-separable two-class dataset. Every background pixel is classified by majority vote of its k nearest training points (Minkowski-p distance, lexsort tie-break — same rule as the code). Small k gives a jagged, high-variance boundary that overfits; large k smooths it toward the global majority (high bias). This is the bias–variance trade-off the course frames around k-NN.

k-NN core — HW01_KNN/HW1_KNN.py

def minkowski_distance(self, x, y):
    return np.sum(np.abs(x - y) ** self.p, axis=1) ** (1 / self.p)

def predict_point(self, x):
    distances = self.minkowski_distance(self.X_train, x)
    # sort by distance, then by label (deterministic tie-break)
    kni = np.lexsort((self.y_train, distances))[:self.k]
    knn = self.y_train[kni]
    counter = np.bincount(knn).astype('uint8')
    max_labels = np.where(counter == np.max(counter))[0]
    if len(max_labels) == 1:
        return max_labels[0]
    # tie: keep only top-vote labels, return the nearest one
    kni_filtered = kni[np.isin(knn, max_labels)]
    return self.y_train[kni_filtered[0]]

Perceptron training loop — HW02/HW2_wet_answers.py

def fit(self, X, y):
    K = np.unique(y).shape[0]
    w = np.array([np.zeros(X.shape[1]) for _ in range(K)])
    while True:
        prev = np.array([w_i for w_i in w])
        for t in range(X.shape[0]):
            y_t = np.argmax(np.dot(w, X[t]))
            if y[t] != y_t:
                w[y_t]   = w[y_t]   - X[t]   # push wrong class away
                w[y[t]]  = w[y[t]]  + X[t]   # pull true class toward x
        if np.array_equal(prev, w):     # no update this pass → converged
            self.w = w; break
