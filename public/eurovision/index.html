Live KCF object tracker — running in your browser

This is a faithful vanilla-JS port of the kcf.py I wrote for the tracking assignment: a Kernelized Correlation Filter. It trains a discriminative filter on a single bounding box entirely in the Fourier domain (RBF kernel correlation + a Gaussian target response + a cosine window), then detects the response peak each frame and adapts the template on-line. The frames are real frames from the course's 284-frame "leaflet" sequence (downscaled to 320×240). No tracking library — the FFT and the filter are implemented from scratch below.

Live Harris corner detector — running in your browser

A faithful port of harris_response + nms2d from local_detector.py. For every pixel it builds the second-moment (structure) tensor from the Gaussian-smoothed gradients M = Gσi ∗ [Ix² , IxIy ; IxIy , Iy²], then computes the cornerness R = det(M) − α·trace(M)² with α = 0.05. The very same separable Gaussian/derivative code from the filtering tab supplies Ix, Iy (spatial_gradient_first_order, scale σd), then a Gaussian integration window σi averages the tensor. A 3×3 non-maximum suppression (nms2d → nms_nd) keeps strict local maxima above the threshold — exactly the harris() pipeline.

Live KLT / Lucas–Kanade point tracker — running in your browser

A faithful port of klt.py (track_klt / klt_compute_updates). These are the real 64×64 test frames (test_data/toy_im_*.png) — a translating letter "A". Click anywhere on the first frame to place tracked points (or press Auto-seed), then Play: each point is tracked frame-to-frame by iteratively solving the 2×2 structure-tensor system for the optimal shift, with sub-pixel bilinear patch sampling (get_patches_subpix):

# per point, iterate klt_max_iter times:
e   = T - I                          # template patch - current patch
Ix2,Iy2,IxIy = (Ix*Ix).sum(),(Iy*Iy).sum(),(Ix*Iy).sum()
Ixe,Iye      = (Ix*e).sum(), (Iy*e).sum()
det = Ix2*Iy2 - IxIy**2              # Cramer's rule 2x2 solve
dpx = (Iy2*Ixe - IxIy*Iye)/det ; dpy = (Ix2*Iye - IxIy*Ixe)/det
p  += (dpx, dpy)                      # refine shift until convergence

Live correspondence problem — matching & RANSAC homography in your browser

The whole wide-baseline-stereo pipeline from the correspondences assignment, ported to vanilla JS. Given two views of the same scene it: (1) detects keypoints in both with the same harris_response + nms2d from local_detector.py; (2) builds a SIFT-style local descriptor per keypoint — a dominant-orientation-normalised 4×4×8 = 128-D gradient histogram (port of calc_sift_descriptor + estimate_patch_dominant_orientation from local_descriptor.py); (3) matches them with mutual nearest neighbours + Lowe's ratio test (match_smnn in matching.py); then (4) RANSAC a homography with a 4-point DLT minimal solver, counting inliers by squared reprojection error and refitting on the inliers (ransac_h / getH / hdist in ransac.py).

KCF — Kernelized Correlation Filter (live above)

Train a filter so that the correlation response peaks at the object center; everything is done in the Fourier domain so it is fast. This is the exact structure of my kcf.py:

# train: solve (K + λI) α = y  in Fourier domain
def kcf_train(x, y, pars):
    k = kernel_correlation(x, x, pars)
    alphaf = fft2(y) / (fft2(k) + pars.lam)
    return alphaf

# detect: response = ifft( alphaf * fft(k(x,z)) )
def kcf_detect(alphaf, x, z, pars):
    k = kernel_correlation(x, z, pars)
    return ifft2(alphaf * fft2(k)).real

def kernel_correlation(x1, x2, pars):
    c = ifft2((fft2(x1).conj() * fft2(x2)).sum(axis=2)).real
    d = (x1**2).sum() + (x2**2).sum() - 2*c
    return np.exp(-1/pars.rbf_sigma**2 * d / d.size)   # RBF

# per frame: peak of response -> shift box; adapt template
dy, dx = argmax(responses) - (cy, cx)
S.x += dx; S.y += dy
S.x_train = (1-gamma)*S.x_train + gamma*patch_next

The JS demo implements fft2 / ifft2 (2D FFT over an arbitrary box size via a 1-D mixed radix-2 + Bluestein transform), the RBF kernel_correlation, the Gaussian target response, the cosine envelope, and the on-line adaptation — matching the params in kcf_params.py (rbf σ=2, γ=0.075, λ=1e-4, cosine window).

KLT — Lucas–Kanade point tracker

Tracks Harris keypoints frame-to-frame by iteratively solving the 2×2 structure-tensor (normal-equation) system for the optimal shift, with sub-pixel patch extraction. From klt.py:

# structure tensor + temporal error -> 2x2 solve (Cramer)
e   = T - I                       # template - current patch
Ix2, Iy2, IxIy = (Ix*Ix).sum(), (Iy*Iy).sum(), (Ix*Iy).sum()
Ixe, Iye       = (Ix*e).sum(),  (Iy*e).sum()
det = Ix2*Iy2 - IxIy**2
dx  = (Iy2*Ixe - IxIy*Iye) / det
dy  = (Ix2*Iye - IxIy*Ixe) / det   # iterate until convergence

Converged correspondences between the first and last frames are then fed to ransac_h to estimate the homography that localizes the planar leaflet (compute_and_show_homography).
