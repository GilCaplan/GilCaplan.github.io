Causal Inference

Warset is observational data, so a raw correlation mixes the effect of a "treatment" with the reasons it occurred. Each question below is estimated three ways — naive (unadjusted), regression / g-computation, and IPW (propensity weighting) — with bootstrap 95% confidence intervals. Where the adjusted estimate moves away from the naive one, confounding was at work. Click a question.

How to read this

• Answer box: Clear effect = all three estimates agree and the adjusted CI excludes zero; Suggestive but fragile = regression-significant but IPW disagrees or is inconclusive (usually thin overlap); No clear effect = the adjusted CI includes zero.
• Forest plot: the dot is the estimated effect; the bar is its 95% CI. If the bar crosses the dashed 0 line, the effect is not statistically distinguishable from none.
• Agreement across methods is reassuring; disagreement (e.g. IPW vs. g-computation) flags fragility — usually thin overlap or model dependence.
• Overlap: the propensity histogram shows whether treated and control units occupy comparable contexts. Little overlap ⇒ the positivity assumption is strained and weights blow up.
Every estimate assumes no unmeasured confounding given the listed adjustment set — an assumption, not a fact. See questions.md for DAGs, literature, and limitations; analyze.py for the code.
