Two Flask apps

HW1 · PictureServer

An app-factory Flask service (create_app()) using a Blueprint. Routes: GET / (web UI), GET /status (JSON uptime + success/fail counters), POST /upload_image (validate & "classify" an uploaded JPEG/PNG, returns ranked matches). Image validation via Pillow; tested with a pytest test_client.

server/website/routes.py · stats.py · templates/index.html
Lab4 · routing & blueprints

Two Blueprints (views, auth) registered on one app. Teaches how a URL maps to a view function and how view returns become HTTP responses: /, /about, /status (200), /secret (401), /login, /logout, /sign-up. Jinja2 template inheritance (base.html → home.html).

The PictureServer API contract — routes.py

methodpathbehaviour
GET/render_template('index.html') — the upload UI
GET/statusJSON: {uptime, processed:{success,fail}, health, api_version}
POST/upload_imagefield image; reject if missing / bad extension / empty / not a real JPEG/PNG (HTTP 400); else return {matches:[{name,score}]}
405(handler)method-not-allowed → JSON error, bumps the fail counter

health flips from "ok" to "error" as soon as any request fails. The classifier is a deliberate mock: it picks 2–4 random labels from a fixed class list, draws random scores, normalises them to sum to 1, rounds to 2 dp and sorts descending — the demo reproduces that exact logic.

Flask routing — type a URL, watch it match a view

Flask's @app.route(path) (here via Blueprints) builds a URL map; an incoming request is matched against it, the view function runs, and whatever it returns becomes the HTTP response (a string → text/html 200; a dict → JSON; a (body, code) tuple → custom status). The upload + classify route — HW1/server/website/routes.py

@bp.route('/upload_image', methods=['POST'])
def upload_image():
    if 'image' not in request.files:
        increment_fail(); return jsonify({"error":{"http_status":400,"message":"No image file uploaded"}}), 400
    file = request.files['image']
    if not allowed_file(file.filename):           # extension in {png,jpg,jpeg}
        increment_fail(); return jsonify({...}), 400
    img_bytes = file.read()
    try:
        img = Image.open(io.BytesIO(img_bytes))     # Pillow: verify it's a real image
        if img.format not in ['JPEG','PNG']: increment_fail(); return jsonify({...}), 400
    except Exception: increment_fail(); return jsonify({...}), 400
    classifications = get_mock_classifications()    # 2–4 labels, scores normalised to sum 1
    increment_success()
    return jsonify({"matches": classifications})

App factory + Blueprint + stats — __init__.py · stats.py

def create_app():
    app = Flask(__name__)
    from . import routes, stats
    app.register_blueprint(routes.bp)              # bp = Blueprint('main', __name__, ...)
    stats.init(); return app
