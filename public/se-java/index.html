HW01 — Sliding tile puzzle + Greedy Best-First solver

A search-agent design: Board → State, transitions are Actions, a Node wraps a state with a parent/action and a heuristic. Search expands nodes from a PriorityQueue ordered by Node.heuristicValue() — the Manhattan distance to the goal — with a visited-set for duplicate detection (exactly as in Search.java). An Action direction names the way a tile slides into the blank.

public int heuristicValue() {                // Manhattan / L1 distance
  for each tile t (value != 0):
    goalRow = (t-1) / cols;  goalCol = (t-1) % cols;
    sum += |r - goalRow| + |c - goalCol|;
  return sum;
}
// Search: PriorityQueue ordered by heuristicValue, HashSet for duplicate detection (greedy best-first)

Click any tile next to the blank to slide it. The solver runs the real Search and animates the action list it returns.

Playlist implements Iterable<Song>, FilteredSongIterable and OrderedSongIterable. Iteration order is controlled by a ScanningOrder and three optional filters. HW04 — Recursion on binary trees

Generic BinNode<E> with left/right children. Two recursive algorithms: PathFromRoot.doesPathExist(root, str) walks the tree matching each character of str against node data, descending to whichever child matches the next char; and LevelLargestSum.getLevelWithLargestSum(root) does a level-by-level BFS and returns the index of the level with the largest data-sum. The buttons below run the exact ported algorithms and animate them.
